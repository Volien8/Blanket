# Одеяло

Графический point-and-click квест на Pygame о руководителе проекта, который пытается довести релиз до заказчиков, пока пять команд тянут один ресурс в разные стороны.

## Запуск

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Окно запускается в FullHD `1920×1080`. Управление мышью или стрелками `←/→`:
выберите зону, нажмите `Enter`, чтобы открыть её. `Esc` возвращает в офис или меню.

В офисе доступны векторные иллюстрации персонажей, перенос текста в кнопках и контекстные подсказки при наведении.

## Структура

- `main.py` — точка входа.
- `game/` — цикл игры, состояние и сцены.
- `data/` — диалоги, события и параметры баланса.
- `save/` — локальный слот сохранения, создаётся автоматически.
- `assets/` — зарезервировано под будущие спрайты и звук; текущая версия использует плейсхолдеры.

Используется `pygame-ce` — совместимая с Pygame реализация, для которой есть готовый пакет под Python 3.14.

## GitHub

Локальный репозиторий создаётся командой:

```powershell
git init
git add .
git commit -m "feat: initial playable prototype"
git branch -M main
git remote add origin <URL_репозитория>
git push -u origin main
```

URL удалённого репозитория намеренно не зашит в проект: его нужно указать после создания репозитория на GitHub.
