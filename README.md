# Одеяло

Графический point-and-click квест на Pygame о руководителе проекта, который за 10 рабочих дней пытается довести релиз до заказчиков, пока пять команд тянут один ресурс в разные стороны.

## Запуск

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py
```

Окно запускается в разрешении `1280×720`. Управление мышью или стрелками `←/→`:
выберите зону, нажмите `Enter`, чтобы открыть её. `Esc` возвращает в офис или меню.

В офисе доступны векторные иллюстрации персонажей, перенос текста в кнопках и контекстные подсказки при наведении.

## Актуальные постановки по проекту

- Действие команды считается выполненным только после выбора конкретного ответа.
- В каждом диалоге есть вариант `Отмена`: он закрывает диалог, не меняет состояние игры и не подсвечивает клетку как активную.
- Выполненные за день команды подсвечиваются в офисе; CEO можно пропускать, если в этот день с ней не требуется общаться.
- Порядок запросов подразделений случайно меняется в начале каждого нового дня и сохраняется вместе с игрой.
- Для обеих FE-команд используется обновлённый портрет `assets/portraits/fe.png`.
- Для отдела Поддержки используется фотография `assets/portraits/support.png`.
- Фотография Техподдержки заменена на актуальный портрет; прежняя версия `support.png` удалена заменой.
- CEO придерживается позиции: достаточно разработать около 10% продукта, объявить его готовым и продать, а проблемы решать позже.
- Кнопка `Назад` не должна перекрывать содержимое сцен и размещается компактно в верхней части экрана.
- Кампания рассчитана на 10 дней; в короткую версию включены самые насыщенные взаимодействиями ситуации: CEO, FE, QA, продажи, Поддержка, заказчики и Legacy.
- Сцены плавно переходят друг в друга, портреты анимируются, а выбранные зоны получают пульсирующую подсветку.
- Диалоги печатаются по буквам; результат решения сопровождается уведомлением, звуковой репликой и доступен для повтора.
- Через `game/audio.py` работают звуки интерфейса и локальные голосовые реплики Silero v4 без фоновой музыки. Раскладка голосов: женские — CEO, Бухгалтерия, Поддержка и Продажи; мужские — BE, FE, QA, Документация, Заказчик и Legacy.
- Доступны три слота сохранения, между которыми можно переключаться в меню.
- Некоторые решения имеют отложенные последствия: например, продажа сырого продукта повышает будущий стресс.
- Действия в Legacy отмечают зону выполненной за текущий день; расходы могут увести бюджет ниже нуля, после чего наступает поражение при завершении дня.

## Структура

- `main.py` — точка входа.
- `game/` — цикл игры, состояние и сцены.
- `game/audio.py` — UI-звуки и голосовые интонации.
- `assets/audio/voices/` — сгенерированные Silero v4 мужские и женские WAV-реплики персонажей.
- `tools/generate_silero_voices.py` — повторная генерация локальных голосовых ассетов Silero v4.
- `data/` — диалоги, события и параметры баланса.
- `save/` — локальный слот сохранения, создаётся автоматически.
- `assets/` — портреты подразделений и персонажей, включая `assets/portraits/fe.png`.

Используется `pygame-ce` — совместимая с Pygame реализация, для которой есть готовый пакет под Python 3.14.
